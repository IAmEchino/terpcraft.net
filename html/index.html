Welcome! 👋😄

Hello, welcome to the website for minecraft.umcpgaming.org, the premier Minecraft server at the University of Maryland!

This server is operated by UMCP Gaming, the largest gaming-related organization at the University of Maryland, with 4100+ members on our Discord server.

minecraft.umcpgaming.org is a Vanilla+ SMP server for the Java Edition of Minecraft. It has been operating on and off since 2018, and almost continuously since 2022.

Interested in joining? 🤔❓

We have a Discord server for the Minecraft server, which can be joined through the UMD Academic Hub
